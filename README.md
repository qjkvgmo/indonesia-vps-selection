## NAT 共享 IPv4 与独享 IPv4：同配置差 Rp30.000/月

这是印尼本地厂商和国际厂商之间最容易被忽略的分水岭。Cloudra 的套餐结构正好把差价摆在明面上：

- **NAT S3**：4 核 / 6GB / 50GB SSD / 20 个端口转发 / 1 个公网 IPv6，Rp50.000/月
- **Cloudra S3**：4 核 / 6GB / 50GB SSD / 1 个独享公网 IPv4 + 1 个 IPv6，Rp80.000/月

两档的 CPU、内存、硬盘完全一样，唯一的区别是 IP：一个用共享公网 IPv4 加端口转发，一个给独享 IPv4。价差 Rp30.000/月，买的就是这一个 IP。

共享 IP 意味着什么，具体到使用上：你只能通过服务商分配的几个端口对外提供服务，公网端口由系统自动挑，不能自己指定 80 或 443；你的域名和别人的域名共用一个 IP 的信誉。做网站访问没问题，但涉及发邮件、接第三方支付回调、装需要固定端口的服务，共享 IP 会一路卡。独享 IPv4 在这些场景里是必需品，不是升级选项。

Evoxt 每台机器标配 1 个 IPv4，第三方整理称额外 IP 可按 $3/月加购；如果你要跑邮件服务，下单前先在开通页确认这个 IP 的性质和反解设置。不需要对外服务、只是跑个内部工具或爬虫，共享 IP 的 NAT 套餐能省下这笔钱。👉 [确认 Evoxt 各档的 IP 配置与加购价格](https://bit.ly/EvoXt)

## “起价”和“续费价”：三个已核验的坑

**标题价不等于最低在售价。** Cloudra 的页面标题写“mulai Rp10.000/bulan”，实际在售的最低档是 NAT S2，Rp25.000/月。差出来的 1.5 倍不是涨价，是标题用了宣传口径。看套餐卡片上的数字，别看标题。

**标价可能不含税。** Jagoan Hosting 明确标注页面价格未包含 PPN 11%，也就是说印尼增值税要另算。国际厂商的美元标价通常也不含各地税费，结账页才是最终数字。

**续费价要单独确认。** Jagoan Hosting 在页面上写了续费同价，这一条对长期使用很关键。Evoxt 这边，第三方评测引述过官网一句原话：“If you order a $2.99 plan. You will pay $2.99”，意思是标价之外没有隐藏的带宽费或 CPU 突发费；但首单价与续费价是否完全一致，公开页面上没有单独的续费说明。按年付之前，在购物车里把计费周期切一遍，看第二年扣多少，两分钟的事。
